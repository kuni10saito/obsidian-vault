# 一人経理部 CLAUDE.md（簡易版）

## この事業所について
- 事業形態: 個人事業主 / 法人（どちらか書く）
- 主要な売上: スタートアップ向けAI導入支援、コンサルティング など
- 会計期: 1月〜12月（個人）または 4月〜3月（法人）
- 消費税: 課税事業者・インボイス発行事業者（T◯◯◯…）/ 免税事業者
- 決算月: 12月末 / 3月末 など

## 勘定科目の分類ルール（実務派版）
- 取引先との飲食は、金額を問わず原則「接待交際費」
- ただし、社内会議・打ち合わせで使ったカフェ等（一人あたり数百円〜千円台）は「会議費」
- Amazon、ヨドバシ、ビックカメラ → 取得価額10万円未満は消耗品費、10〜30万円は少額減価償却資産特例、30万円超は固定資産
- AWS、Google Cloud、ChatGPT、Claude、Cursor → 通信費（サブスク型SaaS）
- Suica、JR、タクシー、Uber → 旅費交通費
- 広告関連（Google Ads、Meta広告、X広告） → 広告宣伝費
- 税理士・弁護士・司法書士への支払い → 支払手数料（個人事業主への支払いは源泉徴収義務の確認が必要）

## 税区分のルール
- 通常の課税仕入（10%） → 税区分コード11
- 軽減税率対象（新聞購読料のみ。紙媒体・定期購読に限定） → 税区分コード21
- 海外SaaSなど「電気通信利用役務の提供」 → リバースチャージ方式の検討要（原則は税区分11で計上し、年間の支払総額が一定を超える場合は税理士に相談）
- 非課税取引（社会保険料、租税公課） → 税区分コード90

## 除外ルール（自動仕訳しない）
- ATM出金・残高調整 → 口座振替として別処理
- 借入金返済（公庫、日本政策金融公庫、ローン） → スキップ
- 社会保険料（年金、健保、源泉税） → スキップ
- 投資・資産運用（証券口座、株式購入） → スキップ
- 給与支払い → 給与計算側で処理するのでスキップ

## 源泉徴収のルール（特に個人事業主への支払い）
- 個人への外注費・支払手数料で金額が月50,000円を超えるものは、源泉徴収対象の可能性があるため自動登録しない
- 該当取引はSlackに「源泉徴収対象確認待ち」として通知し、税理士への確認を待つ
- 対象業種の目安：原稿料、デザイン料、講演料、翻訳料、税理士・弁護士・司法書士報酬

## セキュリティポリシー
- 取引先の住所・電話番号・メールアドレス・銀行口座番号などの個人情報は、Coworkの会話ログ・Slack通知・出力ファイルに残さない
- Coworkに渡す経理データは「日付・内容・金額・取引先名」の4項目のみ
- APIキー・認証情報は絶対に画面に表示しない
- 機微なクライアント（NDAがあるスタートアップ等）の請求書は、Coworkに読ませる前に、受領者・機微な条項部分を手作業で墨塗りする

## 判断の境界線
- 過去3ヶ月に同じパターンの取引があれば、その時の仕訳を踏襲してOK
- 新規取引先への支払いは、必ずSlackに通知して僕の確認を待つ
- 月平均の2倍を超える金額の取引は、自動登録しない
- 「返金」「キャンセル」「訂正」を含む取引は、自動登録しない

- 監査結果 → /経理/ログ/YYYY-MM-audit.md
