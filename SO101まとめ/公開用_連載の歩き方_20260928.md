# この連載の歩き方

**Claude Code に NVIDIA Omniverse を動かしてもらう**、という一点だけで続けている連載です。
日本語で指示を出すと、AIがシーンを組み、物理を解き、ロボットを動かす。それをそのまま記録しています。

気づけば11本になり、**話題が5つに分かれて**いました。番号を整理したので、案内を置きます。

---

## 番号の読み方

**`系統 - 通し`** の2桁です。前の数字が話題を表します。

| 系統 | 何の話か |
|---|---|
| **1-** | Omniverse を実務で使う |
| **2-** | 物理を解く（Modulus → PhysicsNeMo） |
| **3-** | 3Dアバター（Audio2Face） |
| **4-** | ロボット（Isaac Sim・GR00T） |
| **5-** | 地図と車（Cesium）※準備中 |

**どの系統からでも読めます。** 興味のあるところだけ拾ってください。

## ひとつ、うまくできた番号の話

旧番号は **Ⅰ Ⅱ Ⅲ** のあと **（4）（5）…** と切り替わっていて、読者を混乱させていました。

整理していて気づいたのですが、新しい番号は**旧番号ときれいに重なります**。

| 旧 | 新 |
|---|---|
| Ⅰ | **1**-1 |
| Ⅱ | **2**-1 |
| Ⅲ | **3**-1 |
| 2-2 | **2-2**（変わらず） |

琵琶湖の回に付けた `2-2` というラベルは、**新しい体系でもそのまま正しい**。
「Ⅱ（Modulus）の2本目」という意味で付けたものが、そのまま話題番号になっていました。

Ⅰ Ⅱ Ⅲ のほうは公開順でもあったので、どちらのつもりで振ったのかは自分でも判然としません。
ただ **`2-2` を付けた時点では話題で数えていた**わけで、新体系はそれに揃えた形です。
