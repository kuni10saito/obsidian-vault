# Claude Code スキル一覧（経営分析プロジェクト）

## レポート関連

### `/ccs2-download <授業ID> <検索キー>`
CCS2からレポートZIPをダウンロードする。
- 検索キー: 課題名（`第1回レポート`）または日付（`4/22`）
- Playwrightでログイン → レポート一覧 → 課題特定 → ZIPダウンロード
- 例: `/ccs2-download 79707 4/22`

79707 AI概論

79730　データ経営入門

　80260 経営分析
　　　　
### `/summarize-reports <展開フォルダ> <文字数>`
レポートフォルダから学籍番号と要約のCSVを作成する。
- 対応形式: .docx / .pptx
- 出力: BOM付きUTF-8 CSV（学籍番号・概要・ファイル名）
- 例: `/summarize-reports 第1回課題_展開 400`

### `/evaluate-reports <展開フォルダ> [評価基準]`
レポートを10/8/6の3段階で自動評価しCSV出力する。
- テキスト抽出 → 内容評価 → CSV（学籍番号・コメント・点数）
- 評価基準を自然言語で指定可能
- 例: `/evaluate-reports 第2回課題_80260 AIの定義について説明できているか`

### `/review-reports <展開フォルダ> <名簿ファイル> <課題内容>`
提出者のみに問ごとの講評コメントを作成しCSV出力する。
- 名簿（PDF/CSV）から氏名を取得、提出者のみ対象
- 課題内容を自然言語で指定 → 問ごとに個別コメント生成
- 重複提出はタイムスタンプ最新を自動採用
- 出力: BOM付きUTF-8 CSV（学籍番号・氏名・講評）
- 例: `/review-reports 第2回レポート_展開 履修者名簿.pdf "問1:サイモン3段階モデル, 問2:PPDAC具体例, 問3:PPDAC vs PDCA"`

## 試験・採点

### `/grade-pdf <PDFパス> <採点基準>`
スキャンPDF（手書き答案）を画像で読み取り、ページごとに採点する。
- 各ページを画像変換 → 手書き判読 → 採点基準に従い採点
- 採点基準は自然言語で自由記述
- 出力: BOM付きUTF-8 CSV（学籍番号・氏名・各問得点・合計）
- 例: `/grade-pdf テスト2回.pdf "Q1=5で3点, Q3=9で3点, IQR=4で4点, 箱ひげ図10点, 問2 10点, 問3正解1,3,5で20点(誤り・不足各-5)"`

## 学びの軌跡NOTE

### `/portfolio-feedback <PDFフォルダ> [対象ページ]`
学びの軌跡NOTE（PDF）からフォームフィールドを抽出し、フィードバックコメントを生成する。
- ページ1（基本情報）は常に読み取り + 指定ページのフォームフィールド
- 各学生300字程度のフィードバックを生成
- 出力: Markdownファイル + CSV（学籍番号・氏名・コメント）
- 例: `/portfolio-feedback C:\Users\saito\Downloads\学び30 9,10`

## 講義資料

### `/lecture-script <PPTXファイルパス>`
PPTXファイルから講義スクリプト（Markdown）を作成する。
- 各スライド約3分の講義用文章（300〜500文字）
- 講義口調、冒頭に挨拶・最終にまとめ
- 出力: `<ファイル名>_講義スクリプト.md`
- 例: `/lecture-script AI概論4回A pythonV1.pptx`

### `/tts-generate <講義スクリプト.md>`
講義スクリプトからスライドごとの音声ファイルを生成する。
- DGX Spark上のQwen3-TTSモデルで音声クローン生成
- 齋藤先生の声で各スライドのWAVファイルを出力
- 読み辞書（`読み辞書.tsv`）で専門用語の読みを自動補正
- 例: `/tts-generate AI概論3回_講義スクリプト.md`

### `/make-video <PPTXファイル> <音声フォルダ>`
PPTXスライド画像と音声ファイルから講義動画（MP4）を生成する。
- PowerPoint COM → PNG画像エクスポート → ffmpegで結合
- 解像度 1920x1080、音声なしスライドは5秒無音表示
- 出力: `<PPTXファイル名>.mp4`
- 例: `/make-video AI26\AI概論3回（AIの数学）V2.pptx AI26\第3回_読み辞書`

## アドバイザー面談

### `/mendan [インタビュー項目.md]`
自動インタビューアプリ（Gradio）を起動する。
- faster-whisper(tiny) + Claude Haiku(streaming) + Edge-TTS
- 録音停止で自動送信、全6ステップで自動進行
- 面談記録は `面談記録/` に自動保存
- 例: `/mendan` `/mendan アドバイザー面談_インタビュー項目1年生.md`

### `/mendan-summary [面談記録フォルダ]`
面談記録フォルダの.mdファイルを要約してCSV出力する。
- 各面談のGPA・達成事項・課題・目標・資格・将来を要約
- 出力: BOM付きUTF-8 CSV（学籍番号・氏名・日時・所要時間・要約）
- 例: `/mendan-summary 面談記録`

## スケジュール

### `/schedule-csv <CSVファイル>`
スケジュールCSVからWindowsタスクスケジューラにスキルを一括登録する。
- CSV形式: 日時・フォルダ・スキル・引数の4列
- 基点: `C:\Users\saito\Downloads\経営分析`
- フォルダ: `データ経営レポート` / `AIレポート` / `経営分析レポート`
- `--list` で登録済み一覧、`--clear` で全削除
- 例: `/schedule-csv スケジュール.csv`

## コミュニケーション
/teams-send
### ` <CSVファイル> [メッセージテンプレート]`
CSVの内容を各学生のTeamsチャットに自動送信する。
- CSV形式: A列=学籍番号、B列=氏名、C列=メッセージ本文
- Playwrightで Teams Web にログイン → `Alt+Shift+N` で新規チャット → 送信
- パスワードは毎回ユーザに確認（保存しない）
- 例: `/teams-send 学び29_フィードバック.csv アドバイザー面談のフィードバック`
