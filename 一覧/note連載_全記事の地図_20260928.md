## なぜ振り直したか

現在の番号は**3つの数え方が混在**していて、公開順とも内容とも一致していない。

| 問題 | 実例 |
|---|---|
| ローマ数字→算用数字に切り替わる | `Ⅰ` `Ⅱ` `Ⅲ` のあと `（4）` `（5）` `（6）` `（7）` |
| 実質の出発点に番号がない | 2026-03-08「Omniverse を動かす」（→ `活用-1`） |
| 番号なしが3本ある | Modulus使ってみよう / Isaac Sim + GR00T / Skill編 |
| 「2-2」だけ別体系 | Ⅱ（Modulus）の続きだが、公開は `（7）` の後 |
| **Vault内の呼び方とも食い違う** | 下記 |

### ★「Ⅰ」が2本を指していた

[[琵琶湖/琵琶湖_ノート用まとめ]] は **`Ⅰ` を 2026-03-08 の記事**（→ `活用-1`）としている。
しかし **2026-03-30 の記事のタイトルが literally「Omniverse Ⅰ」**（→ `活用-2`）である。

さらに同ノートは琵琶湖の記事を「Ⅲ」と呼んでいるが、実際に公開されたタイトルは
**「Omniverse 2-2」**だった（→ `Mod-3`）。**執筆中に番号が動いている。**

| 注意 | 理由 |

| **URL（記事ID）は変わらない** | note.com はタイトルを変えてもIDが変わらない。既存リンクは生きる |
