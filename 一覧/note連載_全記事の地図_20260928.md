## なぜ振り直したか

旧番号は**3つの数え方が混在**していて、公開順とも内容とも一致していなかった。

| 問題 | 実例 |
|---|---|
| ローマ数字→算用数字に切り替わる | `Ⅰ` `Ⅱ` `Ⅲ` のあと `（4）`〜`（8）` |
| 出発点に番号がない | 2026-03-08「Omniverse を動かす」（→ **序章**） |
| 番号なしが3本ある | Modulus使ってみよう / Isaac Sim + GR00T / Skill編 |
| 「2-2」だけ別体系 | Ⅱ（Modulus）の続きだが、公開は `（7）` の後 |
| **Vault内の呼び方とも食い違う** | 下記 |

### ★「Ⅰ」が2つの意味で使われていた

[[琵琶湖/琵琶湖_ノート用まとめ]] は **`Ⅰ` を 2026-03-08 の記事**（→ **序章**）としている。
しかし **2026-03-30 の記事のタイトルが literally「Omniverse Ⅰ」**（→ `活用-1`）である。

さらに同ノートは琵琶湖の記事を「Ⅲ」と呼んでいるが、実際に公開されたタイトルは
**「Omniverse 2-2」**だった（→ `Mod-2`）。**執筆中に番号が動いている。**
