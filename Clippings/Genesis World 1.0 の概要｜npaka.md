# Genesis World 1.0 の概要（要約）

## 背景
- ロボット開発のボトルネックは「データ不足」だけでなく「モデル開発サイクルの遅さ」
- Genesis AIはシミュレーションを**学習データ生成基盤**ではなく**評価エンジン**として重視

## シミュレーション評価の意義
- 実機評価：数百タスク×数百エピソード → 200時間以上/回
- シミュレーション：同規模を0.5時間未満で実行（2桁以上の高速化）
- 再現性が高く、CI的に継続的なベンチマークが可能
- 実世界データのみで学習したモデルをシミュレーションで評価する方針（過適合を避けるため）

## 信頼性の担保
- 視覚・運動学/動力学・低レベル制御の3層で実機とシムの差分を分析
- 実機とシムを同一初期状態で並列実行し差分を特定
- シム評価と実機ロールアウトの相関＝**89%**、FIDによるリアリティギャップは他シムより**45%**小さい

## Genesis World 1.0 の構成要素
1. **Nyx**：ロボット向けリアルタイム写実レンダラー（1080p・4ms以下描画目標）
2. **Genesis World**：剛体・FEM・MPM・PBD/SPHを統合したマルチフィジックス基盤（IPCより最大103倍高速）
3. **Quadrants**：Python→GPUコンパイラ（Taichi派生、従来比最大4.6倍高速、微分可能）
4. **Simulation Interface**：アセット・センサー・並列環境などを扱うAPI層
5. **シーン/アセット生成パイプライン**：フォトグラメトリによる3D再構築＋自動シーン生成

## 評価設計の工夫
- 視覚・行動・意味の3軸で摂動を分解し、単一パラメータのみ変化させて弱点を特定
- 弱点＝次に集めるべきデータの指針

## 今後の方向性
1. シミュレーション規模でのポストトレーニング拡張
2. 古典シミュレータ×学習型ワールドモデルの**ハイブリッド化**
3. 内側ループ（生成→行動→評価→改善）と外側ループ（実世界デプロイ→エッジケース発見→シム再調整）による**自己進化するPhysical AI**
