# 第18章 VLA基盤モデルの活用 — π0 / GR00T のfine-tune（要約）

## VLAとは
- Vision（視覚）・Language（言語）・Action（行動）を統合するモデル
- カメラ画像＋自然言語指示 → ロボットの行動を直接出力
- LLMと同様の「基盤モデル」パラダイムをロボティクスに導入
  - 大規模データで事前学習 → 少数デモでファインチューニング

## 主要なVLA基盤モデル
- **π0（Pi Zero）**：Physical Intelligence社開発。フローマッチングで滑らかな行動生成。軽量版SmolVLAはLeRobotに統合
- **NVIDIA Isaac GR00T N1.5**：汎用VLA。マルチモーダル入力、クロスエンボディメント対応。SO-101と公式統合、Isaac Lab連携
- **Hi Robot**：階層型VLA。高レベル推論（指示分解）と低レベル実行を分離

## VLAが重要な理由
- ACTは1タスクごとに1から学習が必要
- VLAは既に基本スキル・言語対応を学習済み → 少数デモで高性能達成
- 画像認識・NLPにおける事前学習モデルのファインチューニングと同じ発想

## SO-101での実践フロー（GR00T例）
1. データ収集（実機テレオペ／Isaac Lab、LeRobotフォーマット化）
2. SO-101のエンボディメント設定（関節・カメラ・可動範囲）
3. GR00T N1.5のファインチューニング（GPU必要、クラウド推奨）
4. Isaac Labでの評価（成功率・衝突率・滑らかさ等）
5. 実機デプロイ：**推論サーバー（GPU）**と**制御クライアント（実機）**を分離し、自然言語指示で制御

## 課題と展望
- **計算コスト**：リアルタイム制御には推論高速化が必要
- **データフォーマットの整合**：エンボディメントごとの行動空間・カメラ構成の違い
- **Sim-to-Realギャップ**：Domain Randomizationや実機データ混合で対応
- 汎用ロボット実現に最も近いアプローチとして期待

## まとめ
- VLAは視覚・言語・行動を統合し、言語指示でロボット制御が可能
- 大規模事前学習＋少数デモfine-tuneという基盤モデルパラダイムを導入
- π0・GR00T N1.5をSO-101で少数デモから適応可能
- 次章（第19章）ではπ0.5とコミュニティのファインチューン成果物を使った実践手順を解説
