# 第12章　ロボット学習の主要手法とHIL-SERLの実践（要約）

## 12.1 ロボット学習の全体像
- **模倣学習**：デモから直接学習、報酬設計不要だがデモ依存
- **強化学習**：報酬最大化で自律学習、サンプル効率が課題
- **ハイブリッド**：両者の利点を統合（HIL-SERLが代表例）

## 12.2 主要な模倣学習手法
- **ACT**：軽量（約80M）、50デモで成功率80〜90%。時間的一貫性◎、閉ループ制御は弱い
- **Diffusion Policy**：マルチモーダルな行動分布に強い（平均46.9%改善）。推論が遅く閉ループ反応に弱い

## 12.3 強化学習ベースの手法
- **SAC**：エントロピー正則化でoff-policy学習
- **RLPD**：デモ＋オンラインデータを併用しサンプル効率向上（HIL-SERLの基盤）

## 12.4 HIL-SERL（Human-in-the-Loop強化学習）
UC Berkeley RAIL開発。3フェーズ構成：
1. **報酬分類器の訓練**：成功/失敗画像からResNet18等で二値分類器を作成
2. **初期デモ収集**：SpaceMouse等で20〜30デモ収集
3. **オンラインRL＋人間介入**：Actor/Learnerが並行動作、失敗しそうな時に人間が介入し修正。介入は徐々に減らす

## 12.5 DAgger系・VLA系
- **CR-DAgger**：力覚制御で優しく修正、50修正で成功率+50%以上
- **Diff-DAgger**：不確実性推定で介入タイミングを最適化
- **Hi Robot**：階層的VLA。複雑指示処理でGPT-4oより40%以上高精度

## 12.6 Cosmosとの統合（Sim-to-Real）
- シミュデータと実データを3:7程度で混合
- **Domain Randomization**（物理・照明ランダム化）と**Domain Adaptation**（画像変換）でギャップ軽減

## 12.7 手法比較と選択ガイド
| 手法 | 特徴 |
|---|---|
| ACT | データ効率◎、リアルタイム性◎、汎化△ |
| Diffusion Policy | 成功率◎、リアルタイム性△ |
| HIL-SERL | 全般的に最高性能、訓練時間は中程度 |
| DAgger | バランス型 |
| Hi Robot(VLA) | 汎化◎、データ効率△ |

**タスク別推奨**：
- 精密操作 → HIL-SERL
- 多様な解法 → Diffusion Policy
- 長期複雑タスク → Hi Robot
- データ少 → ACT

**実践フロー**：ACTで土台構築 → 成功率80%未満ならHIL-SERLで改善 → 必要ならCosmos合成データで補強

## 12.8 トラブルシューティング
| 症状 | 原因 | 対処 |
|---|---|---|
| ポリシーが震える | Temporal Ensemble不足 | ensembling重み調整、Diffusionステップ増加 |
| 保守的すぎる | 正則化が強い | kl_weight/温度を下げる |
| Sim-to-Realギャップ大 | 物理パラメータ不正確 | Domain Randomization拡大、実データ比率増加 |

## 12.9 まとめ
- ACT：手軽・高性能（50デモ）
- Diffusion Policy：マルチモーダルに強いが遅い
- HIL-SERL：人間介入で最高性能、手間はかかる
- Cosmos統合：ロバスト性向上

**推奨フロー**：ACTで土台 → HIL-SERLで改善 → 合成データで補強
