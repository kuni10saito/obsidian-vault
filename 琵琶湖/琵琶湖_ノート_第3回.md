## 1. 琵琶湖は、年に一度だけ深呼吸する

夏の琵琶湖は、上が温かく下が冷たい層に分かれている。**上下が混ざらないので、湖底に酸素が届かない。**

冬になると表面が冷えて重くなり、沈む。これが底まで届くと湖全体がかき混ざり、酸素が湖底まで運ばれる。これを**全層循環**という。琵琶湖の「深呼吸」である。

**この深呼吸が、2019年と2020年の冬に止まった。** 記録が残っている中で初めてのことである。

湖底には、この深呼吸だけを頼りに生きている生き物がいる。イサザ、ヨコエビ。止まれば酸素が尽きる。

その後の6年は起きている。**8冬のうち6冬で成立、2冬で不成立。**

## 2. 方程式は、驚くほど短い

ここが今回いちばん面白かったところである。

**この現象を動かしているのは、たった1つの物理である。**

$$\rho(T) = \rho_0\left[1 - \alpha\,(T - 3.98)^2\right]$$

水の密度の式である。ふつうの物質は冷えるほど重くなるが、**水は 3.98℃ でいちばん重く、それより冷えると軽くなる。**

これが二次式（放物線）であることが、すべての鍵である。

- 湖底が 7℃ のとき、表面が 6℃ に冷えれば **表面のほうが重い → 沈む**
- 表面が 3℃ まで冷えると **また軽くなる → 沈まない**

つまり深呼吸には「ちょうどいい冷え方」が要る。温暖化で冬が暖かくなると、表面が湖底より重くなる手前で春が来てしまう。

熱そのものは、素直な拡散方程式である。

$$\frac{\partial T}{\partial t} = \frac{1}{A(d)}\frac{\partial}{\partial d}\left[A(d)\,K(d,t)\,\frac{\partial T}{\partial d}\right] + (\text{日射}) $$

$A(d)$ は**水深 $d$ における湖の面積**である。琵琶湖は逆さにした皿のような形なので、深いところほど面積が小さい。ここを入れないと、深部の熱の出入りを大きく見積もってしまう。

そして $K$ が**混ざりやすさ**。成層が強いほど混ざりにくくなる、という形で書く。

$$N^2 = -2\,g\,\alpha\,(T - 3.98)\,\frac{\partial T}{\partial d}$$

この $N^2$（成層度）が大きいほど $K$ が小さくなる。**「混ざらないから成層が保たれ、成層が保たれるから混ざらない」という自己強化のループ**が、方程式の中に入っている。深呼吸が止まる年があるのは、このループのせいである。

書き下すとこれだけである。難しいのは方程式ではなく、**$K$ の中身を実測に合わせること**だった。

## 3. PhysicsNeMo の利用と限界

### PhysicsNeMo とは何か

NVIDIA が公開している、**物理をニューラルネットで解くためのフレームワーク**である。以前は Modulus という名前だった（シリーズⅡで使ったのはこれ）。天気予報AI「Earth-2」の中身も、同じフレームワークで作られている。

中核にあるのが **PINN（Physics-Informed Neural Network）** という考え方である。

古典的な数値計算はこうする。

> 空間を格子に切る → 各格子点の温度を未知数にする → 連立方程式を解く

PINN はまったく違う。

> 「位置と時刻を入れると温度を返す」ニューラルネットを用意する
> → **方程式そのものを損失関数にして**、それを満たすように学習させる

**格子が要らない。** 解は連続関数として出てくる。そして飛び飛びの実測データを損失に足すだけで一緒に扱えるので、**「方程式は分かっているが、その中のパラメータが分からない」という逆問題**が自然に書ける。

ここは古典手法がいちばん苦手なところである。だから期待した。

### 琵琶湖では、古典手法を乗り越えられなかった

同じ道具を実際の湖に持っていった。結果は正直に書く。

```
PINN（PhysicsNeMo）   631 秒
有限体積法（NumPy）     1.5 秒
```

**400倍以上の差**があり、しかも精度も古典手法のほうが上だった。

これは PhysicsNeMo の欠陥ではない。**この問題が、PINN の長所をひとつも使わない形をしていた**のである。

| PINN の長所    | 琵琶湖の1次元問題では             |
| ----------- | ----------------------- |
| 格子が要らない     | 深さ方向に切るだけ。**格子は困っていない** |
| 解が連続関数で出る   | 60層あれば足りる。**要らない**      |
| 疎なデータを混ぜられる | 気温も日射も**連続で揃っている**      |
| 逆問題が書ける     | 順問題。**未知パラメータが無い**      |

長所が4つとも空振りして、**学習のコストだけが残った。**

そしてこれは、シリーズⅡへの反省でもある。Ⅱで解いた教科書問題がきれいに解けたのは、**あれが PINN の得意な形に整えられていたから**でもあった。整えられていない問題を持ってくると、こうなる。

### 配置を変えた

|         | 担当                                     |
| ------- | -------------------------------------- |
| **計算**  | 有限体積法（NumPy）。1D → 多カラム → 3D            |
| **可視化** | **PhysicsNeMo / ParaView / Omniverse** |
| PINN    | 観測が疎な**逆問題**に温存                        |

**外したのではない。3行目がこれから効く。**

この記事の最後に「次に要る観測」を3つ挙げるが、あれはどれも**疎な観測から未知のパラメータを推定する問題**である。格子も切れないし、データも飛び飛びになる。**そこがPINNの本領**で、今回はまだその手前にいた、というだけの話だった。

## 4. 琵琶湖を3Dにする ― 湖底、粒子、ParaView

### 湖底と陸を、1枚につなぐ

湖底だけを描くと、**湖が宙に浮いて見える。**

そこで国土地理院の標高タイルで周囲の陸地を取り、湖の部分だけを「湖面標高 84.4 m − 水深」に差し替えて、**1枚の連続した標高場**にした。湖岸線のマスクで切り替わるので、段差なくつながる。

東西 63.9 km × 南北 79.9 km、標高 −20 〜 1376 m、524万頂点。

> 国土地理院タイルを使ったものには「国土地理院タイルを加工して作成」の表示が要る。これは義務である。

### 湖の中だけ、深さを10倍にする

ここが効いた。

**琵琶湖の最深部は 104 m。まわりの山は 1376 m。** 同じ鉛直誇張をかけると、湖底は平板にしか見えない。窪みが読めない図に意味はない。

そこで陸と湖で誇張倍率を分けた。

| 湖内の倍率 | 湖底のz | 見え方 |
|---:|---:|---|
| 3（陸と同じ） | −59 | 平板 |
| **10（採用）** | **−788** | **窪みが読める。自然** |
| 30 | −2869 | 盆地は明確だが、湖だけ浮いて見える |

水深0の湖岸では倍率によらず同じ高さになるので、陸との接続は崩れない。

> ただしこれは**表示専用の歪み**である。陸と湖で鉛直スケールが違うので、**この図から傾斜・体積・断面を読んではいけない。**

### 流れは、描かないと決めた

ここが記事Ⅰの答え合わせである。

**このモデルは速度場を解いていない。** 対流はパラメータとして押し込んである。だから**矢印や流線を出せば、それは嘘になる。**

Ⅰの図にあった `Velocity & Streamlines` が、まさにこれだった。

では動きをどう見せるか。**拡散のラグランジュ表現**を使った。

モデルが解いているのは拡散方程式だが、これは**局所の混ざりやすさに応じてランダムウォークする粒子の群れ**とまったく同じものである。だから粒子を撒いて動かせば、**その動きはモデルが解いている式そのもの**であって、飾りではない。

水平には動かさない。動くのは深さだけである。粒子の深度分布が水の体積分布と一致するかを全フレームで検証して、**±0.006 以内**で合っている。

### 滞留日数 ― 粒子でしか出せない量

粒子には履歴を持たせられる。**「最後に表層に触れてからの日数」**である。

貧酸素化とは要するに「深層水が何日ぶんの酸素消費を溜め込んだか」なので、酸素の絵と並べると **貧酸素な水 ＝ 長く表層に触れていない水** として境界がぴたりと一致する。

| 日付 | 酸素 [mg/L] | 滞留日数 |
|---|---|---|
| 03/01（起点） | 11.99 一様 | 0 |
| 12/01 | 2.46〜10.22 | 〜275日 |
| **03/01（1年後）** | **11.95〜12.02 一様** | **〜32日** |

**1年かけて溜めた275日ぶんの澱みが、深呼吸で32日に若返る。** これが琵琶湖の1年である。

### 見せたい量で塗る

![[biwa/fig_overturn_quad2_0219.png]]

成功した年と、循環しなかった年を並べた4画面である。

最初、**失敗例は色分けが読めなかった。** 水温で塗ると成功も失敗も似た色になる。「断面図にすれば差が出るはずだ」という筋の悪い仮説を試して、外している。

**滞留日数で塗り直したら、失敗した年は深層に「古い水」が残り続けるのが一目で出た。**

見せたい量で塗る、というだけの話だが、そこに気づくまで遠回りした。

### 配れる形にする

ParaView で動画を作り、地形つきのモデルは glTF に変換した。Draco圧縮で **338 MB → 26.4 MB**。

ビューアもモデルも埋め込んだ**単一のHTMLファイル**にしてあるので、**ダブルクリックすればブラウザで琵琶湖が回る。** 外部参照ゼロ、オフラインで動く。配るのはこれ1個で済む。

## 5. 3D にして、初めて見えたこと

湖底地形をそのまま格子にして、鉛直60層で解いた。

![[biwa/fig_overturn_terrain_0130.png]]

ParaView で見ると、**深呼吸は湖全体で同時には起きない。**

浅いところから順に、**70〜100日かけて湖を掃いていく。**

```
面積の 5% が循環   11月中旬
       50%        1月下旬
       95%        2月中旬
```

これは1次元モデルでは原理的に見えない絵である。1次元は場所を1つしか持っていないので、「湖の一部だけ循環しない」という状態を表現できない。

**そして、県の判定は「一部水域における全層循環の未確認」という言い方をしている。**

## 6. 「あと1℃」は、本当ではなかった

ここが今回いちばん大きな結果である。

1次元モデルで臨界の温暖化量を出すと、**あと +1.0℃** で深呼吸の発生確率が50%を切る、と出る。

ところが、この計算は**湖全体の平均**を見ている。県が見ているのは**いちばん回復しない場所**である。

**種類が違う量を比べていた。**

3Dで「湖面積の何%が循環しないか」に判定を置き換えると、答えが変わる。

| 判定のしかた | 臨界の温暖化量（現在から） |
| --- | ---: |
| 湖全体の平均（1次元） | +1.00℃ |
| **面積ベース（3D）** | **+0.25 〜 +0.42℃** |

**余裕は半分以下だった。**

そしてこの面積ベースの判定は、**現在の気候での発生確率を 75% と出す**。実測は8年中6年、つまり 75% である。

判定に使う水域を全湖にしても、水深20m以深に絞っても、40m以深に絞っても、**この 75% は動かなかった。** 湖のどこを見るかで答えが変わらない、という意味で、この一致は偶然ではない。

一方、1次元の湖盆平均モデルは「現在の気候で97%の確率で起きる」と予測する。この差は偶然では説明がつかず、統計的に**棄却される**。

## 7. 最後に出た、いちばんきれいな量

**「最後まで循環しなかった面積」** である。

| 年度     | 実際      |     未循環面積 |
| ------ | ------- | --------: |
| 2019年度 | **不成立** | **27.3%** |
| 2023年度 | 成立      |      6.0% |
| その他6年  | ―       |  **0.0%** |

**6%から27%の間のどこに線を引いても、同じ答えになる。**

これまで使っていた水温ベースの指標は、どう調整しても2023年度を「不成立」と誤判定していた。**未循環面積にした途端に直った。**

理由ははっきりしている。**県の判定基準と同じ形の量だから**である。「一部水域における未確認」を、そのまま面積で測っている。

## 8. できないこと

正直に書く。

**年ごとの予測はできない。** 「今年の冬は起きるか」には答えられない。

どのモデルも、どの設定でも、**2018年度と2023年度を取り違える**。この2年の組だけは、どうやっても合わない。

そしてもっと根本的な問題がある。**検証に使える冬が8つしかない。** 統計的な信頼区間は41%〜93%まで広がり、この幅では「どの判定基準が正しいか」を決められない。

冬を増やすには年を待つしかなく、待つと気候が変わって同じ母集団でなくなる。

## まとめ

**やったこと**

- 琵琶湖を実測の湖底地形で3D化した（616セル × 鉛直60層）
- 深呼吸が湖を70〜100日かけて掃いていく様子を可視化した
- PhysicsNeMo を計算から可視化に配置換えした

**わかったこと**

- **「あと1℃」ではなく「あと0.3〜0.4℃」だった。** 判定の取り方が食い違っていた
- 1次元の湖盆平均モデルは統計的に棄却される
- **未循環面積**という診断量が、県の判定といちばん素直に対応する

**わからないこと**

- 年ごとの予測はできない。n=8 の壁

**次に要るもの**

計算では埋まらない穴が3つ、具体的な観測仕様として出た。

1. 異なる水深2地点の**同時深層観測**
2. 水平方向の水温ばらつきの**空間相関構造**
3. 北湖での**染料またはドリフターによる分散実験**

**モデルが行き詰まったのではなく、観測が足りないところまで来た。**

### 教科書の問題と、本物の研究の差

Ⅱで解いた問題は全部きれいに解けた。今回は、そうはいかなかった。

いちばん時間を食ったのはモデルの改良ではなく、**「湖底より下の、存在しないはずの格子と熱をやりとりしていた」というバグ**である。731通りの水深のうち369通り、ちょうど半分で起きていた。これを潰すまで、検証結果も、そこから引き出した結論も、全部間違っていた。

**教科書の問題にはバグが隠れる場所がない。** 答えが分かっているからである。

本物の問題には、答えがない。だから「もっともらしい結果」がそのまま通ってしまう。今回いちばん学んだのは、方程式でも道具でもなく、**もっともらしい数字を疑い続けることのコスト**だった。
