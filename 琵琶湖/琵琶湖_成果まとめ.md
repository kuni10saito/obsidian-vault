# 琵琶湖 全層循環モデル — 成果まとめ

2026-08-29 時点。作業の経緯・失敗した仮説・差し替え前の数値は
`HANDOFF_琵琶湖引き継ぎ1.md` §15〜§21 を参照。本書は**確定した内容だけ**。

---

## 1. 何を作っているか

琵琶湖北湖の**全層循環**（冬に表層と深層が入れ替わり、湖底に酸素が届く現象。
「琵琶湖の深呼吸」）を1次元鉛直カラムで再現し、**温暖化がどこまで進むと
起きなくなるか**を問う。

滋賀県は2019年・2020年にこれが確認できず、貧酸素化が問題になっている。

---

## 2. モデルの構成

3月1日（全層循環直後）に等温・飽和から出発し、400日を有限体積法で解く。

| 要素   | 内容                                                                    |
| ---- | --------------------------------------------------------------------- |
| 鉛直拡散 | `K = K_bg + K_conv·switch(N²) + K_wind·exp(−z/d_wind)/(1+N²/N²_wind)` |
| 湖盆形状 | 面積-深度曲線 A(z) で重み付け（角柱ではない）                                            |
| 熱収支  | 日射を明示し、非日射フラックスを `h·(T_s − T_e)` に分離                                  |
| 気温強制 | 気象庁 彦根の平年値（1991-2020）に第2高調波まで当てはめ                                     |
| 深層DO | 底泥消費 SOD（∝ 湖底接触面積）＋ 水柱呼吸 R_w                                          |

**ソルバ本体 `fd_column.py` は成層抑制の追加1点のみの変更**で、`p` に
`N2_wind` が無ければ従来と完全一致する（後方互換を確認済み）。

`fd_annual_ens.solve_ens()` は `fd_column.solve()` と**機械精度（1.8e-15℃）で
一致**することを確認済み。

## 3. 確定したパラメータ

| パラメータ                 | 値                         | 決めた観測量              | 決まり具合                               |
| --------------------- | ------------------------- | ------------------- | ----------------------------------- |
| **K_bg**（背景鉛直拡散）      | **1.0e-5 m²/s**           | 混合層の深まり（8〜1月）       | **1e-5 に絞れる**（3e-5 で外れる）            |
| **N2_wind**（成層抑制）     | **3.0e-6**                | 8月の躍層 5.7〜9.2m      | 1e-6〜1e-5                           |
| **h_exchange**（湖面熱交換） | **25 W/m²/K**             | —                   | **決まらない**（15/20/25 いずれも可）           |
| **K_bed**（湖底境界混合）     | **3.0e-5 m²/s**           | 深層DOの値・勾配・冬の回復      | 40m以深に限定。**風で変調**（exp=3、時間平均は1に正規化） |
| **SOD_amp**（SODの季節振幅） | **0.9**                   | DO最小の時期             | ピークは8月下旬                            |
| Q_0（非日射フラックス定数項）      | 年平均で正味ゼロの閉じ条件             | —                   | 自由パラメータではない                         |
| SOD                   | **500〜1000** mgO₂/m²/day  | 60m・90m × 10/1・12/1 | **範囲のみ**                            |
| R_w                   | **0.0025〜0.010** mg/L/day | 同上                  | **範囲のみ**                            |

### 決まり具合について

**はっきり決まったのは K_bg・N2_wind・K_bed・SOD_amp。** h_exchange はこの
観測量の組では決まらない。SOD/R_w は**単一の確定値を論文に出さないこと**
（深層DOの季節変化がまだ完全には合っていないため）。

K_bg については、**混合層の深まりが較正に使っていない独立な検証**になっている
（下記 §5）。

### データの扱いで必ず守ること

1. **表層水温は 0.5m ではなく 5m で比べる。** 0.5m は 11〜12時台の測定で
   日中の表層加熱を平均 +0.9℃ 含む。日平均強制の1Dモデルには対応物が無い
2. **深層DOは C点1点ではなく第一湖盆7地点(A〜F,L)の空間平均を使う。**
   同日・同深度でも地点間で 1〜4 mg/L 違う。1Dモデルは水平平均を表す
3. **90m以深の実測は存在しない。** 今津沖中央の最深観測は湖底上1m（約89m）。
   100mプロファイルに依存する較正は原理的に検証不能
4. **全層循環の判定は 0.4℃。** 県が確認しているのは底層DOの回復で、その日の
   実測 ΔT(10m−深層) は 0.1〜0.5℃（平均0.34）残っている。0.2℃判定は厳しすぎる
5. **調査は月2回。** 到達日・最小値はいずれも区間でしか決まらない

### 不成立年は再現できない（8冬すべてで循環する）

実際の気温・風で不成立2冬を含む8冬を回した。

| 年度(冬)         | 実測 成否   | モデル 循環日   |  モデル DO回復 |
| ------------- | ------- | --------- | --------: |
| 2018 (2019年冬) | **不成立** | 01/24     |     +1.11 |
| 2019 (2020年冬) | **不成立** | **02/10** | **+0.69** |
| 2020 (2021年冬) | 成立      | 01/18     |     +0.91 |
| 2021 (2022年冬) | 成立      | 01/16     |     +1.18 |
| 2022 (2023年冬) | 成立      | 01/18     |     +1.11 |
| 2023 (2024年冬) | 成立      | 01/28     |     +0.79 |
| 2024 (2025年冬) | 成立      | 01/24     |     +1.07 |
| 2025 (2026年冬) | 成立      | 01/23     |     +1.02 |

**8冬すべてで循環し、不成立が1年も出ない。** ただし方向は捉えている:

- 不成立2年の平均 02/01 に対し成立6年の平均 01/21（**11日遅い**）
- 2019年度（実測で最も暖かい冬）は **8年中最遅の 02/10**、DO回復も **+0.69 と最小**

しかし 2018年度(01/24) は成立年の 2023年度(01/28)・2024年度(01/24) と重なり、
**2年のうち1年しか分離できない。** あと2〜3週間ぶん「循環しにくく」なる必要がある。

**原因は水平不均一と考えられる。** 県の判定は「**一部水域**における全層循環の
未確認」で、1次元モデルは湖盆平均の1本の柱なので**平均が循環すれば成立**に
なる。実際は全湖盆が揃う必要があり、どこか1箇所でも残れば不成立。
§4 の「同日・同深度で地点間 1〜4 mg/L 違う」も同じ水平不均一である。

## 6. 主結果 — 臨界の温暖化量

**ΔT は気象庁 彦根 1991-2020 平年からの偏差。現在ではない。**

|                 | 彦根 年平均気温 |       ΔT |
| --------------- | -------: | -------: |
| 1991-2020 平年    |    15.0℃ |      0.0 |
| 2018-2025（観測期間） |    16.0℃ | **+1.0** |
| 2026年（1〜8月）     |    16.5℃ |     +1.5 |

330メンバー（ΔT 11点 × 30年）、σ=0.47℃（`jma_hikone.SIGMA_ANNUAL`、実測）。

| ΔT(平年比) |      現在比 |    発生確率 |   到達日 平均   |
| ------: | -------: | ------: | :--------: |
|     0.0 |     −1.0 |    100% |   01月22日   |
| **1.0** | **±0.0** | **97%** | **02月04日** |
|     1.5 |     +0.5 |     70% |   02月11日   |
| **2.0** | **+1.0** | **13%** |   02月13日   |
|     2.5 |     +1.5 |      3% |   02月14日   |
|     3.0 |     +2.0 |      0% |     —      |

- **発生確率が50%以下: 平年比 +2.0℃（現在比 +1.0℃）**
- **10年に1回以下: 平年比 +2.5℃（現在比 +1.5℃）**

> **注意（未解決）**: 現在(ΔT=+1.0)の発生確率が 97% で、実測の 75%
> （8年中6年）より楽観的。**ただし原因は「気温だけを揺らしているから」では
> ない** —— 実際の年別強制で回しても8冬すべて循環する（§5）。
> **モデル自体が循環しやすすぎる。**
>
> したがって論文では、**臨界ΔTは「湖盆平均が循環しなくなる閾値」であり、
> 県の『一部水域で未確認』という判定より甘い**と明記すること。
> 「方向は捉えているが閾値が甘い」という限定つきの主張にする。

## 7. わかった機構 — 気温と風の役割分担

| 現象                       | 決めているもの | 根拠                        |
| ------------------------ | ------- | ------------------------- |
| **深層DOの季節変化**（最小の時期・回復量） | **風**   | 最小日 r=+0.90／気温を年別にしても不変   |
| **全層循環の日**               | **気温**  | 風だけでは sd 0.5日、気温を入れて 4.8日 |
| 全層循環の**成否**              | 両方（示唆）  | 気温だけでは2019/2024の順序がつかない   |

### 風と深層DOの関係（観測）

調査区間ごとの「第一湖盆平均の底層DO変化率」と「期間の平均風速」
（n=63、9〜12月）:

|                      |                           r |
| -------------------- | --------------------------: |
| 素の相関                 |                      +0.587 |
| **季節(t, t²)を除いた偏相関** | **+0.467**（t=+4.06、p<0.001） |
| さらに年度ダミーも除く          |                      +0.465 |

同時期どうしで風の強弱により二分:

| 月   |                風弱 |     風強 |      差 |
| --- | ----------------: | -----: | -----: |
| 9月  | **−0.078** mg/L/日 | +0.008 | +0.085 |
| 10月 |        **−0.055** | +0.021 | +0.076 |
| 11月 |        **−0.045** | −0.000 | +0.045 |
| 12月 |            +0.048 | +0.059 | +0.011 |

**4ヶ月すべて符号が揃う。風の弱い区間は深層DOが減り、強い区間は横ばい〜増加。**

### 実装 — 風による K の変調

```python
f(t) = (W(t)/⟨W⟩)^3        # **時間平均が1になるよう正規化**
K(z,t) = k_eff(T) + K_bed · shape(z) · f(t)
```

**平均を1に固定したのが肝。** K_bed の時間平均は変わらないので、改善が出たら
「平均を上げた」からではなく**間欠性そのもの**の効果である。指数3は風の混合
エネルギーが `u*³ ∝ W³` であることによる。2024年の実測で **上位10%の日が
年間の深部混合の50%を担う**。

これを入れると深層DOの回復が +0.33 → **+1.04**（実測 +1.66）に増える。

### 採用したのは K_bed の変調だけ

同じ風の時系列で `K_wind`（表層混合）や `h_exchange`（湖面熱交換）も変調して
みたが、**どちらも較正済みの水温を壊すので採用しない。**

|                 |   K_bed のみ |    ＋K_wind |             ＋h |
| --------------- | ---------: | ---------: | -------------: |
| DO回復 平均         |      +1.03 |      +1.17 |          +1.17 |
| 循環日 平均絶対誤差      |       5.2日 |       4.8日 |           改善せず |
| **冬の最低水温 バイアス** | **−0.08℃** | **−0.58℃** | **−1.2〜−2.0℃** |

h の変調（バルク式 `H = ρ c_p C_H·U·ΔT`）は物理的には正しいが、
**定数 Q_0 では補償できない。** Q_0 の閉じ条件は「年平均の正味フラックス=0」で
**年平均**しか合わせられないのに、`h ∝ W` は熱フラックスの**季節振幅**を
増やす（冬は風が強く冷却が強まり、夏は弱まる）。数値的に Q_0 を解き直しても
冬が約 0.8℃ 冷たいまま残る（年収支のずれは −3.3 W/m² と定量化できた）。

正しく直すには潜熱を本来のバルク式に戻す必要がある:

```
LE = ρ L C_E · U · (q_s(T_s) − q_a)
```

飽和比湿 `q_s(T_s)` が水温に依存するので**水温が下がれば蒸発も弱まる**という
負のフィードバックが働く。定数 Q_0 ＋ 風変調にはこれが無い。湿度データの取得と
熱収支の再設計を伴うため、現時点では見送る。

## 8. 較正の作法（守るべきこと）

### ① 照合先は必ず一次データから取る

作業中、記憶ベースの照合先が**4つ**誤っていた（彦根平年 年15.63℃→15.0、
8月表層 27〜28℃→5mで28.3〜29.7、8月躍層 15〜20m→5.7〜9.2m、
深層DO年間最小 2〜4→0.5〜2.0 mg/L）。いずれも較正値を大きく動かす。

**照合先は `biwa_obs.py` / `jma_hikone.py` / `jma_wind.py` から引くこと。**

### ② 単年の1点ではなくN年のレンジで採点する

深層水温も冬季最低水温も年々変動が1℃を超える。単年に合わせると3パラメータに
自由度が残らず、「確定した」ように見えてしまう。

### ③ 埋まらない罰則は較正を汚染する

8月表層をスコアに weight 1.0 で入れたまま走らせたところ K_bg=3e-6 が1位に
なった。分解すると勝因は表層項だけで、他の4項目はいずれも 1e-5 の方が
レンジ内だった。**K_bg を下げると熱が深部へ逃げず表層が温まるので、
埋まらない罰則を K_bg が肩代わりしていた。**

対処として `recalibrate_all.core()`（8月表層を除いた外れ量）を分けた。
**K_bg を決めるのは `core` の方。**

### ④ モデルと照合先の気候を揃える

気温曲線は 1991-2020 平年、照合先は 2018-2025 の実測で、**1℃ずれていた**。
`--dT 1.0` で揃えると5観測量すべてがレンジに入る組が出る（dT=0 では0通り）。

### ⑤ 正規化した量を非線形変換すると正規化が壊れる

風の変調係数を `fw = (W/⟨W⟩)³`（平均1に正規化）で作り、熱交換係数 h には
バルク式の1乗が要るので `fw^(1/3)` を使った。**これが誤り。**

```
mean(fw) = 1  だが  mean(fw^(1/3)) ≈ 0.80   （Jensen の不等式）
```

h の実効平均が 25 → 約20 に下がり、冬の冷却が弱まって全層循環が1〜2ヶ月
遅れた。「指数を戻す」つもりが「平均を下げる」ことになっていた。

**h 用の係数は独立に `fh = W/⟨W⟩` で作る**（平均は定義から厳密に1）。

一般化すると、**変調を入れたらその量の時間平均が意図どおりか必ず印字して
確認すること。** 意図した効果ではなく意図しない平均のシフトが結果を支配する
事故は、本プロジェクトで3回起きている（他は §③ と §⑥）。

### ⑥ ソルバが2つあると片方が取り残される

- 旧 `fd_ensemble.py` は `fd_column.solve()` と別実装で **A(z) が無かった**
- `calibrate_do_annual.py` は `N2_wind`・`h` を渡しておらず**成層抑制が無効**

どちらも結果を大きく変える事故だった。**新しい項を入れたら、それを使う
すべてのドライバを確認すること。**

### ⑦ 通年計算に `fd_column.diagnose()` を使わない

初期が完全混合なので**必ず初日を返す**。専用の `diagnose_annual()` を使う。

## 10. 論文の限界節（下書き）— 1次元であることの限界を定量的に述べる

§6 の注意書きは「限定つきの主張にする」と方針だけを決めていた。
**2026-09-02〜03 の検証で数字が入った**ので、そのまま使える形にしておく。
根拠はすべて `HANDOFF_琵琶湖引き継ぎ1.md` §21。

### 10.1 主張の骨格

**「1次元だから水平不均一を扱えない」で終わらせない。**
必要量を示し、実測と突き合わせ、埋められない理由まで書く。この順で書くと
「怠慢による限界」ではなく「**データの制約による限界**」だと示せる。

```
① 何が足りないか   … 空間の min 判定に必要な分散が 0
② どれだけ足りないか … 必要量 0.94〜1.41℃
③ 実在するのか     … 中層の実測は 95%点 2.28℃ で、必要量と同じ桁
④ なぜ確かめられないか … 深層は観測が存在しない。4手とも全滅
```

### 10.2 使う数字

| 項目 | 値 | 出典 |
|---|---|---|
| 判定の食い違い | 県は「**一部水域**で未確認」＝空間の min / 1Dは湖盆平均＝mean | §5 |
| 循環日の再現 | MAE **5.2日**、Pearson +0.674（**平均は合っている**） | §5 |
| 不成立年 | 8冬すべて循環。2年のうち1年しか分離できない | §5 |
| 必要な遅れ | あと **2〜3週間** | §5 |
| **必要な水平ばらつき** | **0.94℃（14日）〜 1.41℃（21日）** | §21.1 |
| モデルが持つ量（同深度） | **厳密に 0.00℃** | §21.2 |
| モデルが持つ量（深さ違い・循環時） | 0.08℃ | §21.2 |

### 10.3 書き方の案

> 本モデルは1次元鉛直カラムであり、湖盆平均の1本の柱として全層循環を判定する。
> 一方、滋賀県の判定は「**一部水域における**全層循環の未確認」であり、
> 空間の最小値に対する判定である。平均が循環すれば成立となる本モデルは、
> 定義上この判定より甘い。
>
> この差を定量化した。較正済みモデルの循環直前における鉛直温度差の減少速度は
> 0.067 ℃/day であり、全層循環を実測に整合する 2〜3 週間遅らせるには
> **同深度で 0.94〜1.41 ℃ の水平温度ばらつき**が必要である。
> 本モデルが同深度に持つばらつきは**厳密にゼロ**である（温度を深さのみの
> 関数として解くため）。
>
> この必要量が物理的に実在しうるかを、琵琶湖環境科学研究センターの
> 水深別調査2地点（今津沖中央・南比良沖中央）で確認した。冬季（12〜3月）の
> 同深度水温差は 30〜40 m で **絶対値平均 0.43 ℃、95 パーセンタイル 2.28 ℃、
> 最大 3.20 ℃** であり、**必要量は実測される振幅の範囲内にある**。
> ただし平均では必要量に届かず、上位の事例で超える。全層循環の成否は
> 最も厳しい時期に全域が揃うかで決まるため、平均ではなく上位の値が効く。
>
> **深層（90 m）における水平温度差は観測が存在しない。** 同センターの
> 水深別調査は北湖で2地点のみ実施され、うち90 m級は今津沖中央1地点である。
> 第一湖盆7地点の底層データは溶存酸素のみで水温を含まない。
> 溶存酸素のばらつきから水温ばらつきを推定する試みは、本モデルにおいて
> 深層水温と溶存酸素が実質的に独立に振る舞う（秋から冬にかけて90 m水温は
> 0.19 ℃しか変化しない）ため、必要量の 1/10〜1/30 という桁違いの値しか
> 与えなかった。
>
> したがって本研究が示す臨界温暖化量は、**湖盆平均が循環しなくなる閾値**で
> あり、県の判定より甘い側に偏る。方向性と感度は捉えているが、
> 絶対値としての閾値は上限側の推定と解すべきである。

### 10.4 併せて書くべき副次的結果

**溶存酸素のまだらさと、全層循環に効く水平不均一は別物である可能性が高い。**

- 第一湖盆7地点の同日・同深度DOは |幅| 平均 1.75 mg/L（n=243、§18.15）
- しかし深層で水温とDOは実質独立（§21.8 手3）
- **風は深層DO変化率と有意に相関する**（冬季を含む偏相関 +0.467, p<0.001、§18.19）
  が、**同深度の水温差とは無相関**（冬季 +0.013, p=0.93、§21.8 手4）

同じ風が、同じ手法で、DOには効き水温差には効かない。
**前者は底泥消費と局所混合の問題、後者は密度場の問題**として分けて論じるのが
妥当である。§18.13.6 は両者を「同じ欠落」と読んでいたが、**修正を要する。**

### 10.5 書いてはいけないこと

- **「3D化すれば解決する」と書かない。** 必要量が実在する振幅の範囲内という
  ところまでしか言えていない。対流そのものは3Dでも解像できず（§9、
  プルーム幅〜100 m に対し領域幅11.9 km）、現業の湖沼モデルも
  パラメータ化している
- **中層の実測値を深層に外挿しない。** 内部波起源なら躍層付近で最大となり、
  深層では小さいはずで、外挿は楽観側に偏る
- **双子実験（§10）の定量値を引かない。** 較正前であり、閾値の枠組み自体が
  ΔT掃引に変わっている（§10 の注意書き）

## 11. ファイル

DGX Spark 上は `~/biwa_sym/`（system python3.12 + numpy、**GPU不要**。
150通り掃引で約360秒、330メンバーのアンサンブルで約800秒、DO 420通りで約250秒）。

### データとその読み出し

| ファイル                                   | 内容                             |
| -------------------------------------- | ------------------------------ |
| `sym/biwa_obs.py`                      | 今津沖中央の実測と照合先。**較正の照合先はここから引く** |
| `sym/biwa_obs_data.json`               | 水深別プロファイル＋第一湖盆7地点の底層DO（50KB）   |
| `sym/jma_hikone.py`                    | 彦根の平年値・月別実測(1990〜)・σ・気温曲線      |
| `sym/jma_wind.py` + `wind_hikone.json` | 彦根 日別風速 3165日（2018〜2026）       |

### ソルバと較正

| ファイル                          | 内容                                                       |
| ----------------------------- | -------------------------------------------------------- |
| `sym/fd_column.py`            | ソルバ本体                                                    |
| `sym/fd_annual_ens.py`        | ベクトル化通年ソルバ（fd_column と機械精度一致）                            |
| `sym/fd_seasonal.py`          | 気温・日射・熱収支の強制                                             |
| `sym/hypsography.py` + `.npz` | 面積-深度曲線 A(z)                                             |
| `sym/recalibrate_all.py`      | K_bg × N2_wind × h の同時再較正（**`--dT 1.0` 必須**）             |
| `sym/calibrate_do_annual.py`  | 深層DO較正。`--kbed` `--wind-year` `--wind-exp` `--temp-year` |
| `sym/fd_ensemble_annual.py`   | アンサンブル（主結果）                                              |

### 実行例

```bash
python recalibrate_all.py --curve jma2 --dT 1.0 --nz 100
python calibrate_do_annual.py --nz 100 --kbg 1e-5 --kbed 3e-5 \
    --wind-year 2024 --wind-exp 3 --temp-year 2024
python fd_ensemble_annual.py --nz 100
python biwa_obs.py        # 照合先を全部表で出す
python jma_wind.py        # 冬ごとの強風日数と成否
```
