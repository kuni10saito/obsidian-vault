# 湖底の酸素が戻るしくみ ― 見えない波と、月1回の観測の落とし穴

前回の記事（2-2）では、琵琶湖の「深呼吸」が止まる問題を3Dで解いた。湖底地形をそのまま格子にして、深層循環が湖を70〜100日かけて掃いていく様子を可視化した。

そこで書かなかったことがある。**湖底の酸素が回復するしくみを、モデルが再現できなかった。**

## 1. 観測で見えているもの

深層（水深90m）の溶存酸素は、夏から秋にかけて下がり続ける。湖底の泥が酸素を消費するからである。

ところが、ときどき **+1〜3 mg/L の急な回復** が入る。下がって、戻って、また下がる。ギザギザしたノコギリ波の形になる。

この回復があるから、湖底の生き物はなんとか持ちこたえている。

## 2. 拡散では作れない

モデルの酸素輸送は「拡散」で書かれている。表面の酸素が高く、深層が低い。この濃度差にしたがって、酸素がじわじわ下に降りていく。

問題は、**降ろせば降ろすほど濃度差が縮まる**こと。拡散は自分で自分の原動力を消してしまう。

K（混ざりやすさ）をどう調整しても、モデルが出せる回復量の上限は **+0.33 mg/L**。観測の +1.3〜1.7 mg/L に対して5分の1以下。

風の空間変動も入れた。底の境界混合も入れた。風のランダムな揺らぎも入れた。**何を入れても +0.33 から動かない。**

拡散の枠の中では、この問題は閉じない。

## 3. 湖の中の見えない波

強い風が琵琶湖を吹き抜けると、水面だけでなく、水中の温度の境界面（温かい水と冷たい水の境目）も傾く。風が止んでも、この傾きは元に戻ろうとして揺れ続ける。**内部セイシュ**と呼ばれる、湖の内部の波である。

北湖では、この波の周期が約 **3日**。目には見えない。

揺れに伴って、境界面の下に上下方向の流れが生じる。拡散と違い、これは**水の塊ごと動かす流れ**である。濃度差を平らにするのではなく、酸素の多い水をそのまま深層に押し込む。だから自分の原動力を消さない。

## 4. 4つの数字で表す

内部セイシュを直接計算するには、流体の運動方程式を3次元で解く必要がある。それは今のモデルの枠を超える。

代わりに、**セイシュの効果だけを4つの数字で表して**、酸素の輸送に組み込んだ。

| 数字 | 意味 | 値 |
|---|---|---|
| 振幅 | 境界面がどれだけ揺れるか | 20 m |
| 周期 | 1回の揺れにかかる時間 | 3 日 |
| 減衰 | 風が止んだ後に揺れが弱まる速さ | 5 日 |
| 深さ減衰 | 深くなるほど揺れが弱まる距離 | 30 m |

しくみは単純で、

1. 風が吹くと揺れが大きくなり、止むと弱まる
2. 揺れが大きいほど上下の流れが強い
3. 境界面の近くがいちばん強く、深くなるほど弱まる

この流れで酸素だけを運ぶ。温度には手を付けない（温度の層構造を壊さないため）。

## 5. ノコギリ波が出た

![[do_timeseries.png]]

### 拡散だけのモデル（従来）

90m 深の酸素は**単調に下がり続ける**。最低 8.4 mg/L。観測（0.6〜2 mg/L）よりずっと高い。回復はほとんど起きない。

### セイシュを入れたモデル

**400日のうち254日で、酸素が前日より増えている。** 3日周期で上下を繰り返す、ノコギリ波が出た。

| | 従来（拡散のみ） | セイシュ入り |
|---|---|---|
| 酸素の最低値（日ごと） | 8.4 mg/L | **1.2 mg/L** |
| 酸素の最低値（月ごと） | 8.4 mg/L | **2.5 mg/L** |
| 最大の回復量（1日あたり） | +0.33 | **+5.8** |
| 最大の回復量（月ごと） | ― | **+2.5** |
| 酸素が最も少ない日 | 345日目 | **257日目（11月中旬）** |

1日あたり +5.8 mg/L は大きく見えるが、これはセイシュの半周期（1.5日）で上下する瞬間値で、観測では拾えない。

**月ごとに見ると +2.5 mg/L。観測の +1〜3 mg/L とほぼ一致する。**

## 6. 月1回の観測の落とし穴

セイシュの周期は3日。観測は月に1回。

**周期の10倍も粗いサンプリングなので、振動を正しく捉えられない。** ある月はたまたま波の山で測り、次の月は谷で測る。規則的な3日振動が、ランダムな上下に化ける。

これが、観測で酸素がノコギリ波に見える理由である。

モデルが示しているのは、「ランダムに見える回復は、実は3日周期の規則的な振動の見かけの姿だ」ということである。

## 7. 底の泥ではなく、水の中の消費が効く

意外なことに、**底の泥の酸素消費（SOD）を12倍にしても、酸素の最低値はほぼ変わらなかった。**

理由は、消費が起きる場所にある。底の泥は湖底のごく近くの水からしか酸素を奪えない。90mの測定点は底から14m上にあり、泥の影響が拡散で届くのに約1年かかる。

効いたのは、**水の中で起きる消費**（微生物の呼吸、有機物の分解）である。これは深さに関係なく全層で均一に酸素を減らす。この値を 0.01 → 0.025 mg/L/日 に上げたことで、月ごとの最低値が 5.1 → 2.5 mg/L に下がった。

## 8. 流れの向きの話

前回、水平方向の循環（環流）の可視化を進めていた。その過程で、**環流がどちらに回っているかを決められない**という問題に当たった。

JEBAR（海底地形が流れの向きに及ぼす効果）という項の符号が、教科書によって異なっていた。そこで運動量の式から自分で導き直した。結果は「反時計回り」。検算の相関は 1.00000 で一致した。

**ただし、「湖全体の平均の渦度（回転の強さ）」で測ると、逆の答えが出る。** 湖の中に時計回りの部分と反時計回りの部分が共存しているためで、平均の取り方で答えが変わる。

流速の**大きさ**と**季節変化**は測り方によらず安定している。**向き**だけが測り方に依存する。

## まとめ

| | 拡散だけ | セイシュを入れた |
|---|---|---|
| 最大回復量 | +0.33 mg/L（観測の1/5） | **+2.5 mg/L/月（観測と一致）** |
| 酸素の最低値 | 8.4 mg/L（高すぎる） | **1.2 mg/L（観測に整合）** |
| ノコギリ波 | 出ない | **出る** |

ポイントは3つ。

1. **拡散は自分の原動力を消す。流れは消さない。** これが「構造的に無理」だった理由と、セイシュで解けた理由
2. **月1回の観測は粗すぎる。** ノコギリ波に見えるのは、3日周期の振動の見かけの姿
3. **底の泥ではなく、水全体で起きる酸素消費が深層を支配している**

できないことも変わっていない。年ごとの予測はまだできない。検証に使える冬は8つしかなく、この壁はモデルの改良では超えられない。

### 計算の道具

前回と同じ。Claude Code + NVIDIA Jetson。モデルは NumPyの有限差分法で、1回の400日走行は数分。感度分析（20〜30ケース）はバックグラウンドで並列実行した。
