## 2. 状態方程式と成層度

淡水の密度は 3.98℃ で最大になる。**この2次の非線形性が全層循環そのもの**
なので、線形近似は使えない。

$$\rho(T) = \rho_0\left[1 - \alpha\,(T - T_{md})^2\right]$$

浮力振動数の2乗（$z$ は上向き、$z = H - d$）:

$$N^2 = -\frac{g}{\rho_0}\frac{\partial \rho}{\partial z}
      = 2\,g\,\alpha\,(T - T_{md})\,\frac{\partial T}{\partial z}
      = -2\,g\,\alpha\,(T - T_{md})\,\frac{\partial T}{\partial d}$$

> **深度で書くと符号が反転する。** `fd_multicol` / `fd_lake3d` は深度基準
> なので負号がつく。移植のとき最初に間違えた箇所（§28.3）。
>
> $T < T_{md}$（4℃以下）では**符号が反転する**。表層が冷たいほど軽い
> 逆成層になる。これが冬に成立する。

## 3. 熱の式（1次元カラム）

湖盆形状 $A(d)$ で重み付けした鉛直1次元。**水平方向には解いていない。**

$$A(d)\,\frac{\partial T}{\partial t}
 = \frac{\partial}{\partial d}\!\left[A(d)\,K(d,t)\,\frac{\partial T}{\partial d}\right]
 - \frac{1}{\rho_0 c_p}\,\frac{\partial}{\partial d}
   \Big[A(d)\,(1-\alpha_{alb})\,Q_{sw}(t)\,e^{-d/\lambda}\Big]$$

第2項が日射の水中吸収。**湖面で全部吸わせず、指数減衰で分配する。**

### 3.1 鉛直拡散係数

$$K(d,t) = K_{bg}
 + K_{conv}\,S(N^2)
 + \frac{K_{wind}\,e^{-d/d_{wind}}}{1 + \max(N^2,0)/N^2_{wind}}
 + K_{bed}\,R(d)\,f_w(t)$$

**対流スイッチ**（不安定なら 1、安定なら 0 へ滑らかに）:

$$S(N^2) = \tfrac12\left[1 - \tanh\!\left(\frac{N^2 + N^2_{thresh}}{N^2_{scale}}\right)\right]$$

> $N^2_{thresh}$ は**中立成層（$N^2=0$）で $S=1/2$ になってしまうのを避ける
> オフセット**。これが無いと深層が勝手に冷える（§9 の罠表）。

**成層抑制**（第3項の分母）は「層に分かれていると風では混ざらない」の表現。
$K_{conv}$ には tanh スイッチがあるのに $K_{wind}$ に抑制が無い、という
非対称が **8月の表層水温を5℃低くしていた**（§15.9.5）。

**湖底境界混合**（$K_{bed}$ の深度形）は、単位体積あたりの湖底接触面積に比例:

$$R(d) = \min\!\left(\frac{r(d)}{r(90)},\,5\right)\cdot
         \mathrm{clip}\!\left(\frac{d - 40}{10},\,0,\,1\right),
\qquad r(d) = \frac{|dA/dd|}{A(d)}$$

> 40m より浅い側をゼロへ落とすのは、$r(d)$ が 20m でも 90m の 9% あって
> **躍層を削ってしまう**ため。境界混合は本来 躍層より下の現象である。

### 3.2 風による時間変調

$$f_w(t) = \frac{\big(W(t)/\langle W\rangle\big)^{3}}
                {\big\langle (W/\langle W\rangle)^{3}\big\rangle_t}$$

**分母で時間平均を1に規格化してあるのが肝。** $K_{bed}$ の時間平均は
変わらないので、改善が出たら「平均を上げた」からではなく
**間欠性そのもの**の効果である（§7）。指数3は $u_*^3 \propto W^3$ による。

> $f_w$ を $1/3$ 乗して $h$ に使ってはいけない。凹関数なので Jensen の
> 不等式により平均が1を下回る（実測で約0.83）。$h$ 用は $W/\langle W\rangle$
> をそのまま使う（§7 の罠）。

## 4. 境界条件と強制

### 4.1 湖面 —— 非日射フラックス分離形

下向き正味フラックス:

$$Q_{net}(t) = (1-\alpha_{alb})\,Q_{sw}(t) - h\,\big[T_s(t) - T_a(t)\big] - Q_0$$

$Q_0$ は自由パラメータではなく、**年平均の正味フラックスがゼロ**という
閉じ条件で決まる:

$$Q_0 = (1-\alpha_{alb})\,\langle Q_{sw}\rangle - h\,\Delta T_{lake},
\qquad \Delta T_{lake} = \langle T_s - T_a\rangle = 1.5\ \text{K}$$

> **従来の $h(T_s - T_{air})$ は「正味の熱交換すべて」を表す平衡温度形**
> だった。そこへ日射をそのまま足すと**二重計上**になり、平衡水温が
> 気温 +6.7℃（年平均21℃）と実際の琵琶湖（約16℃）から大きく外れる（§15.4）。

### 4.2 湖底

$$\left.\left(K\frac{\partial T}{\partial d}\right)\right|_{d=H} = 0$$

**残った日射は最下層で吸収させる**（$e^{-H/\lambda}$ ぶんを最下セルに繰り入れる）。

### 4.3 気温 —— 彦根の平年値に第2高調波まで

$$T_a(t) = c_0 + \Delta T
 + c_1\cos\omega t + c_2\sin\omega t
 + c_3\cos 2\omega t + c_4\sin 2\omega t
 + \delta T_{yr}(t)$$

$\omega = 2\pi/365.25$、$t$ は年通日。$\Delta T$ は**平年（1991-2020, 15.0℃）
からの一様オフセット**で、温暖化シナリオはこれを振る。
$\delta T_{yr}$ は年別の月別偏差（月央に置いて線形内挿）。

> **$\Delta T$ は現在からの偏差ではない。** 観測期間 2018-2025 は既に
> $\Delta T = +1.0$。ここを取り違えると結果が1℃ずれる（§6）。

### 4.4 日射 —— 快晴時の日平均に一様な透過率

$$Q_{sw} = \tau_{atm}\,\frac{S_0}{\pi}\,E_0\,
 \big[\omega_s \sin\phi \sin\delta + \cos\phi \cos\delta \sin\omega_s\big]$$

$$\delta = 0.409\sin\!\left(\frac{2\pi\,\mathrm{doy}}{365.25} - 1.39\right),
\quad \omega_s = \arccos(-\tan\phi\tan\delta),
\quad E_0 = 1 + 0.033\cos\frac{2\pi\,\mathrm{doy}}{365.25}$$

$S_0 = 1361$ W/m²、$\phi = 35.3°$、$\tau_{atm} = 0.42$（彦根の平年値に整合）。

## 5. 溶存酸素

$$A(d)\,\frac{\partial O}{\partial t}
 = \frac{\partial}{\partial d}\!\left[A(d)\,K(d,t)\,\frac{\partial O}{\partial d}\right]
 - A(d)\,R_w
 - \mathrm{SOD}_{\mathrm{eff}}(t,O)\,\left|\frac{dA}{dd}\right|$$

**第3項の $|dA/dd|$ が肝**。各層が接する湖底面積であり、深いほど
体積に対して湖底が効く（§5 の $r(d)$ と同じ幾何因子）。

$$\mathrm{SOD}_{\mathrm{eff}} = \mathrm{SOD}(t)\cdot\frac{O}{K_m + O},
\qquad
\mathrm{SOD}(t) = \mathrm{SOD}\left[1 + a\cos\frac{2\pi(\mathrm{doy}-240)}{365}\right]$$

- **Monod 項** $O/(K_m+O)$ は較正できていない。DO が 0 にクランプされるのを
  防ぐ**数値的な理由**で入れている（§18.13.3）
- **季節振幅** $a = 0.9$（ピーク8月下旬）。沈降有機物は夏のブルーム後に多い。
  **DO 最小の時期を 02/10 → 12/02 に直したのはこれ**（§18.17.3）
- $R_w$ には Monod を掛けていない。90m の収支を支配するのは SOD

**湖面**: $O = O_{sat}(T_s)$ 固定（大気交換は季節スケールに対して十分速い）

$$O_{sat}(T) = 14.652 - 0.41022\,T + 7.991\times10^{-3}T^2 - 7.7774\times10^{-5}T^3$$

> **SOD と $R_w$ は単一の確定値を出さないこと。** 範囲でしか決まっていない
> （SOD 500〜1000 mgO₂/m²/day、$R_w$ 0.0025〜0.010 mg/L/day）。

## 6. 多カラムモデル（§28）

$A(d)$ を **$N$ 本の角柱カラム**に分解する。カラム $k$ は水深 $H_k = k\,\Delta z$、
水平面積 $a_k$。

$$a_k = A(c_k) - A(c_{k+1})\ \ (k<N),\qquad a_N = A(c_N)$$

$c_k$ はセル $k$ の中心深度。こう置くと**各深度で生存カラムの面積和が
厳密に $A$ になる**:

$$\sum_{k\ge m} a_k = A(c_m)$$

### 6.1 各カラム

角柱なので $A$ が分子分母で消え、§3 の式で $A \equiv$ const とした形になる。
**面積が効くのは (a) 水平交換の重み と (b) 湖盆平均をとるときだけ。**

$$\frac{\partial T_k}{\partial t}
 = \frac{\partial}{\partial d}\!\left[K\frac{\partial T_k}{\partial d}\right]
 - \frac{1}{\rho_0 c_p}\frac{\partial}{\partial d}
   \Big[(1-\alpha_{alb})Q_{sw}e^{-d/\lambda}\Big]
 + \underbrace{\frac{\bar T(d) - T_k(d)}{\tau_h}}_{\text{水平交換}}
 + \xi_k(d,t)$$

$$\bar T(d) = \frac{\sum_{k\in\mathcal{A}(d)} a_k\,T_k(d)}
                    {\sum_{k\in\mathcal{A}(d)} a_k},
\qquad \mathcal{A}(d) = \{k : H_k > d\}$$

**面積加重平均を使うので $\sum_k a_k(\bar T - T_k) = 0$、熱は厳密に保存する。**

- $\tau_h \to 0$ で全カラム同温 ＝ **1次元 + $A(z)$ に一致**
- $\tau_h \to \infty$ で独立カラム ＝ **地形だけの分散（99日）**

### 6.2 確率的な水平擾乱 $\xi$

実測の水平不均一は**平均ゼロで符号が日々入れ替わる変動**である
（§21.4: 30m で 平均差 +0.040℃ / $|$差$|$平均 0.447℃ / **SD 1.149℃**）。
定常緩和 $\tau_h$ が作れるのは系統差だけなので、**形が合わない。**

そこで**偏差そのものを Ornstein–Uhlenbeck 過程にする**。緩和項は既にあるので、
分散を釣り合わせる白色増分を足すだけでよい:

$$T'_k \leftarrow b\,T'_k + \sigma_\xi\sqrt{1-b^2}\;z_k,
\qquad b = e^{-\Delta t/\tau_h},\quad z_k \sim \mathcal{N}(0,1)$$

$T'_k = T_k - \bar T$。**定常SDが $\tau_h$ によらず $\sigma_\xi$ になる**ので、
実測を直接入れられる:

$$\sigma_\xi = \frac{\mathrm{SD}(\text{2地点の差})}{\sqrt{2}}
             = \frac{1.149}{\sqrt2} = 0.81\ \text{℃}$$

> **$z_k$ は各深度で面積加重平均をゼロに引き直すこと。** 体積加重で
> 1回だけ抜くと各深度の平均が保存されず、**毎ステップ再適用されるので
> 累積ドリフトする**（2日で38℃。§28.11）。
>
> **実現SDは $\sigma_\xi$ より小さい。** 鉛直混合も偏差を消すため。
> $\sigma_\xi$ は「実測SDを実現する値」に較正が要る。

## 7. 3次元モデル（§29）

実測の湖底地形 $H(x,y)$ の上で、水平は**拡散だけ**で結ぶ。

$$\frac{\partial T}{\partial t}
 = \frac{\partial}{\partial d}\!\left[K\frac{\partial T}{\partial d}\right]
 - \frac{1}{\rho_0 c_p}\frac{\partial}{\partial d}
   \Big[(1-\alpha_{alb})Q_{sw}e^{-d/\lambda}\Big]
 + K_h \nabla_h^2 T$$

$$\nabla_h^2 T \simeq
 \frac{T_{i+1,j}-2T_{i,j}+T_{i-1,j}}{\Delta x^2}
+\frac{T_{i,j+1}-2T_{i,j}+T_{i,j-1}}{\Delta y^2}$$

**陸・湖底より下のセルとは繋がない**（フラックスゼロ）。
交換は反対称なので**熱は厳密に保存する**。

### 7.1 移流を入れる場合（§30）

$$\frac{\partial T}{\partial t} + \nabla\cdot(\mathbf{u}\,T)
 = \frac{\partial}{\partial d}\!\left[K\frac{\partial T}{\partial d}\right]
 + K_h \nabla_h^2 T + \text{（日射項）}$$

$\mathbf{u}$ は §7.3 で解く。**流束形で書く**ので離散でも熱が厳密に保存する。

### 7.2 $K_h$ と $\tau_h$ の対応

$$\tau_h \sim \frac{L^2}{K_h}$$

$L = 10$ km なら $K_h = 10$ m²/s が $\tau_h \approx 116$ 日。
**§28.9 で効いた $\tau_h = 100$ 日は $K_h \approx 10$ m²/s に当たり、
Okubo 則の範囲（1〜100 m²/s）の中にある。**

### 7.3 水平循環 —— 風と地形が作る順圧流

**§13 以来「速度場は解いていないので出さない」を守ってきたが、ここで解く。**
方針は変えていない —— **解いた範囲でしか出さない**、は同じ。

深さ積分した輸送 $\mathbf{U} = \int_0^H \mathbf{u}\,dz$ [m²/s] について、
**定常・線形底面摩擦・コリオリ**の運動量:

$$R\,U_x - f\,U_y = \frac{\tau_x}{\rho_0} - g H \frac{\partial \eta}{\partial x},
\qquad
R\,U_y + f\,U_x = \frac{\tau_y}{\rho_0} - g H \frac{\partial \eta}{\partial y},
\qquad R = \frac{r}{H}$$

連続の式 $\nabla\cdot\mathbf{U} = 0$ は**流線関数**で自動的に満たす:

$$U_x = -\frac{\partial \psi}{\partial y},\qquad U_y = +\frac{\partial \psi}{\partial x}$$

湖岸で $\mathbf{U}\cdot\mathbf{n} = 0 \iff$ **岸で $\psi$ 一定**。
湖は単連結なので $\psi = 0$。

**運動量を $H$ で割ってから回転を取ると $\eta$ が厳密に消える**
（$\nabla\times\nabla\eta = 0$）。残るのが本体:

$$\boxed{\ \nabla\cdot\!\left[\frac{r}{H^2}\nabla\psi\right]
 + f\,J\!\left(\psi,\ \frac{1}{H}\right)
 = \nabla\times\!\left(\frac{\boldsymbol{\tau}}{\rho_0 H}\right)\ }$$

$J(a,b) = a_x b_y - a_y b_x$。**第2項が地形性ロスビー波の演算子**で、
これがあるので流れは**等深線に沿う**（topographic steering）。

風応力: $\boldsymbol{\tau} = \rho_a C_D |W| \mathbf{W}$、
$\rho_a = 1.225$ kg/m³、$C_D = 1.3\times10^{-3}$。

**スケール**（$f = 8.4\times10^{-5}$ s⁻¹ at 35.3°N、$r = 10^{-4}$ m/s）:

$$\frac{f}{R} = \frac{f H}{r} \approx 40
\quad\text{（回転が摩擦を圧倒＝ほぼ地衡流）},
\qquad
\mathrm{Ro} = \frac{U}{fL} \approx 0.06
\quad\text{（非線形項は落としてよい）}$$

**結果**: 北風に対して**浅い側が順風（−4.7 cm/s）、深い側が逆風（+0.5 cm/s）**。
Csanady の**地形性2環流**。流速は岸沿い 10〜17 cm/s、深部 0〜2 cm/s
（`biwa/fig_lake_flow.png`）。

### 7.4 入っていないもの（流れ）

| | |
|---|---|
| **傾圧流** | 密度成層が作る流れ。**琵琶湖の第一環流はこれ**で、順圧モデルでは原理的に出ない |
| **エクマン螺旋** | 流速の鉛直構造。深さ一様な順圧流だけ |
| 非定常 | 内部波・セイシュ |
| 非線形項 | $\mathbf{u}\cdot\nabla\mathbf{u}$。Ro=0.06 なので無視 |

> **第一環流を出したと誤解させないこと。** 夏の成層期に見える環流は
> 傾圧の現象である。図のタイトルにも
> `NOT solved: baroclinic flow, Ekman spiral, seiche` と焼き込んである。

### 7.5 離散化 —— 保存を壊さない置き方

**$\psi$ は格子の頂点に置く。** セル中心に置くと面を通る流量を $\psi$ の差で
書けず、離散的な非発散が保証されない。頂点なら

$$\text{面を通る流量} = \text{両端の頂点の } \psi \text{ の差}$$

となり、セルまわりで望遠鏡的に打ち消して $\nabla\cdot\mathbf{U} = 0$ が**厳密**。

鉛直流量は連続の式から作る。$W_k$ を層 $k$ の上面を下向きに通る流量として

$$W_0 = 0,\qquad W_{k+1} = W_k - D_k$$

$D_k$ は層 $k$ の水平発散。**列の総発散はゼロなので湖底で厳密にゼロに戻る。**

移流は**風上差分の流束形**:

$$\text{面の熱流束} = q\cdot T_{\text{風上}},
\qquad T_{\text{風上}} = T_a\ (q>0),\quad T_b\ (q<0)$$

**検証（すべて機械精度）**

```
div(U)                     1.8e-12   （流量の代表値 1.1e+04）
岸での U·n                  0.0       （厳密）
層別流量の合計 = 面の流量     3.4e-13   （代表値 3.7e+03）
断熱・移流のみ20日の全熱量    相対差 0.00e+00
後方互換 flow=None          0.0
```

## 8. 粒子（可視化用）

§3 の拡散方程式と**ラグランジュ的に等価**なランダムウォーク（伊藤形）:

$$dz = \frac{\partial K}{\partial z}\,dt + \sqrt{2K}\;dW$$

**粒子の動きはモデルが解いている式そのもの**なので飾りではない。
**水平には動かさない**（1次元モデルに水平流は無い）。

数値スキームで守ること（§可視化 3.1）:

| 要件                         | 理由                                       |           |         |
| -------------------------- | ---------------------------------------- | --------- | ------- |
| **Visser の中点法**            | 素朴な形は $K$ が急変する混合層底で破綻する                 |           |         |
| $K$ を $\sigma = 3$m で鉛直平滑化 | $K$ は1格子で3桁跳ぶ。平滑化しないと $dt$ をいくら下げても合格しない |           |         |
| $dt \le 60$ 秒              | 実測で決めた値。解析式 $1/\max                      | d^2K/dz^2 | $ は甘すぎる |

**滞留日数**は粒子でしか出せない量:

$$\mathrm{age}(t) = t - \max\{s \le t : z(s) \ge z_{5\mathrm{m}}\}$$

## 9. 判定条件

### 全層循環

**成層が立ち上がった後に**崩れた日を採る。初期が等温なので、
これをやらないと必ず初日を返す（§15.9.3）。

$$t_{ov} = \min\Big\{t > t_{str} \;:\; \big|T(10\text{m}) - T(H)\big| < 0.4\ \text{℃}\Big\}$$

$$t_{str} = \min\Big\{t : \big|T(10\text{m}) - T(H)\big| > 1.0\ \text{℃}\Big\}$$

- **0.4℃ の根拠**: 県が確認しているのは底層DOの回復で、その日の実測
  $\Delta T$ は 0.1〜0.5℃（平均0.34）残っている。**0.2℃ 判定は厳しすぎる**（§4-4）
- 浅いカラムでは 10m が湖底に近すぎるので $\min(10, 0.2H)$ を使う

### 空間の min と mean

$$t_{ov}^{\text{県}} = \max_{\text{地点}} t_{ov}(\text{地点})
\qquad\text{（一部水域でも未確認なら不成立）}$$

$$t_{ov}^{\text{1D}} = t_{ov}\big(\text{面積加重平均のカラム}\big)$$

> **この2つの食い違いが §27 の発見である。** 同じ物理・同じ較正値のまま、
> **判定の取り方を変えるだけで不成立年の時期が出る**（湖盆平均 01/31 に対し
> 最深部 03/02、実測の不成立年は 02/25 と 03/22）。

## 10. 離散化と安定条件

有限体積法。セル中心に $T$、界面に流束 $F$（下向き正）:

$$\frac{dT_i}{dt} = \frac{F_{i-1/2} - F_{i+1/2}}{\Delta z\,A_i},
\qquad F_{i+1/2} = -K_{i+1/2}\,\frac{T_{i+1}-T_i}{\Delta z}\,A_{i+1/2}$$

**時間積分は陽解法**。$K$ は対流時に4桁跳ね上がるので固定 $\Delta t$ では壊れる。
毎ステップ次を満たすように刻む:

$$\Delta t < 0.4\,\frac{\Delta z^2}{K_{\max}}\cdot
 \left[\max_i \frac{A_{i+1/2}}{A_i}\right]^{-1}
\qquad\text{かつ}\qquad
\Delta t < \frac{1}{4K_h\left(\dfrac{1}{\Delta x^2}+\dfrac{1}{\Delta y^2}\right)}$$

実際には**鉛直が律速する**（$\Delta t \approx 96$ 秒）。
$K_h$ が 2500 m²/s を超えて初めて水平が効きはじめる。

**計算コスト**（400日、$n_z=60$）:

|             |     実時間 |        1D比 |    格子点 |
| ----------- | ------: | ---------: | -----: |
| 1D + $A(z)$ |    45 秒 |         1× |     60 |
| 多カラム 60本    |    91 秒 |         2× |  3,600 |
| 3D 616セル    | 25〜40 分 | **33〜53×** | 36,960 |

> **格子点が60倍でも多カラムは2倍にしかならない。** numpy がベクトル化し、
> ステップ数が支配するため。**3D で初めて跳ねる。**
